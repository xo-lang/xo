# 0127: The self hosted parser, checked through a canonical syntax tree dump

Status: Accepted (2026-10-10). Implemented in `selfhost/parser/` (Xo),
`internal/ast/text.go` (`ast.Text`), `internal/parser/dump.go`
(`parser.Dump`), `cmd/xo/astdump.go` (hidden `xo astdump`),
`internal/selfhost/parser_test.go` (`TestSelfhostParserDifferential`,
`TestSelfhostParserXoTests`), and `internal/progen` (the program
generator of decision 0110, moved out of a test file). Evidence:
`bench/results/selfhost-parser-2026-10-10.md`. Second step after
decision 0076 (the lexer).

## Context
The self hosted lexer proved itself against the Go lexer with a text dump
both print. The parser is the next component; its output is a tree, so it
needs a text form that two implementations can print identically, that
diffs well when they disagree, and that cannot hide a wrong position.

## Decision
- **Dump format** (`ast.Text`, one node per line): `label: Kind span
  attrs`, children indented two spaces under their parent, the root
  `File span name="..."`. Kind is the Go type name of the node, a span is
  `line:col:offset-line:col:offset` (as in the token dump), attributes
  are the scalar fields in declaration order, snake_case (strings quoted
  byte by byte like the token dump and always printed, true booleans as a
  bare name, ints as `name=N`, operator kinds by their Go constant name
  `op=PlusAssign`, a rune as its code point, the string kind as
  plain/triple/raw, `[]string` as `links=["a","b"]`); child fields follow
  in declaration order, list elements as `field[i]: ...`, nil children
  omitted, and an empty list that Go keeps non nil as `field: []` (a
  variant's fields, `use c ... uses none`, a pattern's fields). The Go
  side is generated by reflection, so a new AST field changes the dump
  and fails the differential test until the Xo parser has it too.
- **`xo astdump [--sig] [--bench=N] <files...>`** (hidden like
  `lexdump`) prints `== <file>`, the tree, and one `diag <code>
  <line>:<col>-<line>:<col> "<message>"` line per diagnostic. `--sig` is
  signature mode, for the std declaration files.
- **Acceptance is compared exactly, diagnostics are not (yet).** The Xo
  parser stops at its first error (the current token becomes the final
  Eof, so every loop ends) and prints only that diagnostic. The test
  requires: every file the Go parser accepts has a byte identical dump,
  and every file the Go parser rejects is rejected by the Xo parser too.
  The habit checks of decision 0087 are ported as rejection conditions
  without their recovery (a habit is always an XO0177 error in Go), so
  the sets agree even on programs such as `throw(e)` or `{lambda: 1}`
  that the bare grammar would accept. The one habit that parses without
  a diagnostic, Go's `for k, v := range x` (reported by the checker), is
  ported whole (`go_range`).
- **Structure.** `selfhost/` is now one Xo module
  (`github.com/xo-lang/xo/selfhost`, `selfhost/xo.mod`) so the parser
  imports the lexer package; a package with a `main` stays importable, so
  `selfhost/lexer` keeps its CLI. The parser package mirrors
  internal/parser: `ast.xo` (Go interfaces become enums: Expr, Stmt,
  Decl, Type, Pattern, Clause; nodes held only by their own type are
  structs), `parser.xo` (tokens, lists, errors, docs, declarations,
  types), `stmt.xo`, `expr.xo` (precedence climbing as core 15),
  `pattern.xo`, `dump.xo`, `main.xo` (CLI, `--bench=N`).
- **Inputs of the differential test**, on the go, arm64, and llvm
  backends, under `-short` too: every repository .xo file, std/*.xo in
  signature mode, the spec's code blocks, programs from `progen.Program`
  (24 under `-short`, 150 full), and token level mutations of repository
  files (300 / 2000: delete, duplicate, swap a token, or insert a
  fragment from a list of brackets, operators, keywords, and habits).

- **Habits and soft errors, compared exactly (2026-10-10, decision
  0141).** The habit checks of decision 0087 are ported whole
  (selfhost/parser/habits*.xo): messages, spans, and the recovery to the
  Xo form, so XO0177 and the other soft errors (XO0161, XO0162 after `}`,
  XO0165 after `is`, XO0169, XO0170 in a parameter list, XO0173, XO0174,
  XO0175 between arms, XO0176, XO0178, and the lexer errors a habit
  renames or drops) no longer stop the Xo parser. A hard error still
  does, and the Xo dump then prints only the diagnostics. The test now
  requires, besides agreement on acceptance: every file the Xo parser
  parses to the end (it prints a tree) has a byte identical dump, tree
  and diagnostics included, and every file whose Go diagnostics are all
  habits (`habitOnly`) is parsed to the end. Fixes and notes are not
  ported (stage 7 of decision 0141).
- **Resynchronization, every dump compared (2026-10-10, decision
  0141).** A hard error no longer stops the Xo parser: like
  internal/parser it sets `bad` (further errors of the statement,
  member, arm, or declaration are suppressed), goes on, and
  resynchronizes where that ends (`sync_stmt` in blocks, member lists,
  and arms; `sync_top` between declarations), with the Go parser's
  messages and spans for every hard error. The dump always prints the
  recovered tree, and the test compares every file's dump byte for byte,
  accepted or rejected.

## Consequences
- A change to internal/parser or internal/ast must be made in
  selfhost/parser in the same change, or `go test -short ./...` fails.
- Diagnostics of the Xo parser: since 2026-10-10 the soft errors and
  habits with their recovery, and every hard error with the Go parser's
  resynchronization (identical dumps on 20,000 token mutations per seed,
  seeds 1 to 3 and the default); the fixes and notes remain (stage 7 of
  decision 0141).
- Writing the parser found two arm64 backend limits (decision 0128).

## Alternatives
- **Reuse `xo parse --ast` JSON**: nested JSON diffs badly (one change
  moves many lines), the spans lack offsets, and nil and empty lists
  look the same.
- **A hand written Go printer**: would not notice new AST fields.
- **Compare diagnostics too**: requires porting all recovery and every
  habit message first; acceptance agreement catches grammar drift now.
- **Generic Xo nodes (kind, attrs, children)**: trivial to dump, but
  useless to the later self hosted checker, which needs a typed tree.

# 0132: Mascot is Finan the fennec fox

Status: Accepted (2026-10-10). Chosen by the owner.

## Context
Go has the gopher, Rust has Ferris, Perl has the camel. A mascot gives
the project a recognizable face for docs, the website, release notes,
and merch. Xo had none.

## Decision
Xo's mascot is **Finan the fennec fox**.

On 2026-10-10 a web search found no programming language or other
software project using a fennec fox as its mascot, and no tech mascot
named Finan. Nearby uses to keep distinct from:

- Mozilla's "Fennec": the old code name for Firefox on Android, still
  the name of the F-Droid build ("Fennec F-Droid"). This is a product
  name, not a mascot.
- Fennekin: a Pokémon based on a fennec fox. Finan's art must not
  resemble it.
- Finnegan the fennec fox: the Chattanooga Zoo's costume mascot. It is
  not in tech, so it does not conflict.

## Consequences
- Logo, docs, and website art may use Finan. No artwork exists yet.
- Pending: a trademark search (USPTO, and EUIPO if relevant) for
  "Finan" in software classes 9 and 42 before Finan appears on merch or
  in a registered logo.
- Pending: an art license. Go's gopher is CC BY 4.0, which lets the
  community make derivative art. Choose one when the first artwork lands.

## Alternatives
- No mascot: rejected; the owner wants one.
- Another animal: not considered. The owner chose the fennec fox
  directly.

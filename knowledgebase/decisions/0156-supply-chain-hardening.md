# 0156: Supply-chain hardening

Status: Proposed (2026-10-11). Number claimed; the supply-chain agent
fills in Context, Decision, Consequences, and Alternatives.

Scope (owner, 2026-10-11): only the consumer's vouches count for
`use c ... uses none`; an effect lock by default in xo.lock
(`--accept-effects` to widen); capability attenuation (for example
`os.net.only(hosts)`); `xo audit`; a replication of the Backstabber's
Knife Collection attacks; the ambient logging channel.

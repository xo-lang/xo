## Context

The native backends (arm64, LLVM, `--no-gc`) link the C runtime std/llrt
(14 files, 26,240 lines on 2026-10-12). Decision 0150 (amended order,
item 6) asks for a pilot: write one piece of it in Xo, `xo_unicode.c`
(1,783 lines), and decide on that evidence whether to port more.

`xo_unicode.c` was data only: Go's case ranges and the letter, digit, and
`strconv.IsPrint` ranges as C arrays, generated by `TestUnicodeTables`.
Its users were C: `n_to_case` (Str and Rune `to_lower`/`to_upper`, the
`a.to_lower() == b.to_lower()` comparison `xo_str_eq_lower`), the Rune
classes, strconv quoting (`Str.quote`, `Rune.quote`, `Bytes.quote`, the
duration parse error), and `xo_unicode_ranges` (std/regexp's `\pL`,
`\p{Nd}`, decision 0172). Porting the tables alone would leave C reading
Xo data, so the pilot ports the tables and every user of them.

Constraints: output identical to the Go backend; the self hosted
compiler mirrors the checker and SSA builder (work in Xo source under
std/native is shared, compiler changes are made twice); the runtime pack
(decision 0157) is keyed by the C sources; another agent writes a wasm
backend (selfhost/wasm), which cannot link C.

## Decision

1. **Runtime modules.** A runtime module is `std/native/llrt/<name>.xo`,
   module path `native/llrt/<name>`. It is loaded when an implementation
   module (std/native/<name>.xo, the native prelude) or another runtime
   module imports it, never for user code (module not found, as for
   `native/rt`), and only for native builds. It is checked like an
   implementation module (`Native`, no std module implemented) and
   compiled **with the program** by the ordinary SSA builder and
   backends: no precompiled Xo in the runtime pack, no new symbol
   convention, no C ABI export. Only reachable functions are emitted.
2. **Tables are Bytes constants.** Each table is a `pub const X: Bytes =
   b"..."` of 24 bit big endian values, emitted as static data (a Bytes
   literal is an `OpConst`), read with `b[i]` (an inline load). A
   `const List[Int]` would be built at first use and read through
   `const_once`, a C call per access. `TestUnicodeTables` now writes
   `unicode_tables.xo` from the same Go tables (Unicode 15.0.0).
3. **C callers.** None remain: every C user of the tables moved to Xo
   with them (case mapping, classes, quoting, regexp ranges, the lower
   compare). The SSA builder's lowering of `a.to_lower() ==
   b.to_lower()` calls the native prelude's `str_eq_lower` (Xo) instead
   of `xo_str_eq_lower` (mirrored in selfhost/ssa). Rule for later ports:
   a C function that needs a ported function is ported with it, or the
   port waits; C never calls compiled Xo (that would need an export
   symbol convention in both backends and both compilers, and every
   program would have to emit the callee).
4. **What stays C: bulk byte moves.** Xo has no inline byte store into a
   string under construction: `BytesBuilder.write_byte` is a C call per
   byte, and narrowing conversions (`UInt8(x)`, `Rune(x)`) are checked C
   calls. The text operations therefore build their result in a Str
   through `rs_*` intrinsics (appended in place when unique) and append
   unchanged stretches in one call: `rt.rs_append_bytes(s, b, lo, hi,
   mode)` copies `b[lo..hi]`, mapping ASCII letters for mode 1 (lower)
   or 2 (upper). All Unicode policy (tables, decoding, which runes
   change, escapes) is Xo. `Rune(UInt8)` is free, so ASCII results of
   `Rune.to_lower` go through a 256 byte table.
5. **Performance bar.** No measurable slowdown on Str heavy work:
   `bench/perf/unicode` (to_lower and to_upper of ASCII and of mixed
   script text, the lower compare, the Rune classes, Rune case mapping,
   quoting) on both native backends, instructions retired and best
   times. RESULT_PLACEHOLDER
6. **Go or no go for xo_rt.c.** PORT_PLACEHOLDER

## Alternatives

- **Precompile the Xo runtime into the pack.** Would need a C ABI export
  convention and stable symbols in both backends and both compilers, and
  objects per backend; rejected for the pilot: compiling with the
  program costs only the reachable functions and keeps one pipeline.
- **C keeps the string loops and calls Xo per non ASCII rune.** Keeps
  ASCII speed without the bulk primitive, but needs the export
  convention above and forces the callees into every program.
- **Tables as `const List[Int]`.** One `const_once` C call and a list
  index per probe; rejected for Bytes constants.
- **Keep the C path selectable.** Not needed: see the performance bar
  result; the C versions remain in git history (1df3176~1).

- [0050-arm64-closures-boxes-equality.md](0050-arm64-closures-boxes-equality.md): the arm64 backend lowers closures (`blr x0`, deferred environment drops), boxes, structural equality helpers, and values past eight words (stack helper arguments, results in the caller's stack argument area).
- [0051-arm64-match-dispatch.md](0051-arm64-match-dispatch.md): native arm64 lays out `match` compare chains as runs of tests and uses jump tables only from 8 values (tables lose on unpredictable tags on Apple M4).
- [0052-recursive-boxing-from-type-graph.md](0052-recursive-boxing-from-type-graph.md): the SSA builder boxes recursive types from the checker's type definition graph, one box per cycle at the edge out of its least user type by name, independent of the order types are first met (supersedes 0048's boxing rule).
- [0053-float-comparison-total-order.md](0053-float-comparison-total-order.md): Float `==` is IEEE (NaN differs from itself, also in aggregates); `<`, `<=`, `>`, `>=`, sort, min/max/clamp use the Ord total order (NaN last, -0.0 equal to 0.0, receiver kept on a tie); `-0.0` is negative zero; native lowering with `fccmp` / paired `fcmp`.
- [0054-arm64-loop-optimizations.md](0054-arm64-loop-optimizations.md): native arm64 loops get pointer induction variables for non power of two element sizes, Int value ranges (unchecked multiplies, masks for `% 2^k`), rotation at a bounds check, `ldp` pairs, and latch layout around inner loops; bounds checks all stay (removing proved ones slowed nbody). Bounds check part superseded by 0184.
- [0055-http-request-values-scoped-middleware.md](0055-http-request-values-scoped-middleware.md): std/http typed request values (`http.Key[T]`, keyed by name and type, process local), middleware that may fail (`wrap` takes `! E`, mapped like handler errors), `Router.mount(prefix, sub)` for scoped middleware, `Listener.addr()` / `Server.addr()`, `Request.with_header`.
- [0056-std-crypto.md](0056-std-crypto.md): `std/crypto` (sha256, hmac_sha256, constant time `equal`, `random_bytes`/`token` through the `Rand` capability, PBKDF2-HMAC-SHA256 `hash_password`/`verify_password`) on the Go standard library only; scrypt/Argon2 deferred (x/crypto is not a dependency). Argon2id added by 0059.
- [0057-test-log-capture.md](0057-test-log-capture.md): under `xo test` each test has its own log sink; records are buffered and printed only on failure (or `-v`), and `testing.logs() -> List[log.Record]` returns them for assertions.
- [0058-shared-reference-counts.md](0058-shared-reference-counts.md): native reference counts are thread local (positive, plain) until a value crosses threads and is marked shared (negative, atomic; Lean/Koka style), literals immortal and read only; per thread heaps; tested with share probes and ThreadSanitizer; tasks emit OpShare at every crossing since decision 0068.
- [0059-argon2id-vendored-from-x-crypto.md](0059-argon2id-vendored-from-x-crypto.md): `crypto.hash_password_argon2id` (OWASP defaults, PHC format) and prefix dispatch in `verify_password`; Argon2id and BLAKE2b vendored from golang.org/x/crypto into std/rt (portable Go, BSD license) instead of a module dependency, so builds stay offline for every target.
- [0060-arm64-latch-copies.md](0060-arm64-latch-copies.md): a conditional branch to a latch moved by `placeLatches` (an inner loop guard that skips the loop) gets an inverted branch and a copy of the latch (sieve 1.4 percent fewer cycles); loop bounds checks stay because nbody's slowdown from removing them is a layout effect of the loop's size. Bounds check part superseded by 0184.
- [0061-derive-sqlrow-and-returning.md](0061-derive-sqlrow-and-returning.md): `derive SqlRow` (prelude marker, structs of column types) decodes std/sql rows by column name; `row.decode[T]()`, `query_as[T]` and `query_one_as[T]` on Db and Tx; `RETURNING` on INSERT, UPDATE, DELETE in the in memory driver, read through `query`.
- [0062-conversion-hint-and-small-std-additions.md](0062-conversion-hint-and-small-std-additions.md): XO0601 on an unknown associated function of a numeric type with one numeric argument adds the note and first fix `Float(x)`; `Duration.from_secs_int`; `Response.text()`.
- [0063-mutex-with-read.md](0063-mutex-with-read.md): `Mutex.with_read` gives shared read only access (many readers or one writer) with writer preference; barging in real runs, FIFO handoff under test (decision 0047); a `var` closure parameter for a by value function type is XO0401.
- [0064-mutex-stays-on-runtime-lock.md](0064-mutex-stays-on-runtime-lock.md): real run `Mutex` keeps the cancelable runtime lock; a sync.RWMutex prototype (no cancellation) gained nothing in bench/perf/http once hold times were fixed; site bookkeeping moved out of the critical section.
- [0065-heap-goal-floor.md](0065-heap-goal-floor.md): Xo programs keep the GC heap goal at or above a floor (2 MiB per P, at least 16 MiB) with GOGC=100 growth above it, tuned after every cycle; `gc` lines in xo.mod configure it, GOGC/GOMEMLIMIT/XO_GC_MIN_HEAP in the environment win.
- [0066-request-arenas-by-default.md](0066-request-arenas-by-default.md): request scoped arenas are on by default (`--no-arenas` opts out); the audit table of every way a request value can escape, three holes found and fixed (recorder kept arena bodies, Go callbacks ran with the request's arena on other goroutines, mounted middleware kept arena responses).
- [0067-go-callback-tasks.md](0067-go-callback-tasks.md): a Go callback called on another goroutine is a child task with its own thread, held mutexes, and scheduler turn (`rt.GoCallback`, goroutine identity by `curG`); one called on the caller's goroutine during a Go call runs as the caller; gobind format 3.
- [0068-native-task-runtime.md](0068-native-task-runtime.md): the native backends run scopes, tasks, channels, select, Mutex, and Atomic on a worker thread pool (work stealing deques, helping joins and awaits, a new worker while others block), unwind cancellation through explicit checks that close scopes and return zero values, pass values to the runtime as shared lists of one, detect deadlocks exactly; the deterministic scheduler stays on the Go backend.
- [0069-native-event-loop-fibers.md](0069-native-event-loop-fibers.md): native tasks run on fibers (own stacks, hand written switch, every wait parks and frees the worker; chosen over continuations: no change to SSA or backends); one poller thread (kqueue/epoll, timer heap, self pipe) for sleep, `after`, `with_timeout`, TCP sockets, and SIGINT/SIGTERM two phase shutdown; thread locals only through noinline accessors.
- [0070-native-defer.md](0070-native-defer.md): `defer` on the native backends is lowered inline at every exit of its block (end, return, `?`, break, continue, unwinding, with scopes closed in nesting order) and shielded by `rt.shield_begin`/`rt.shield_end`; a fault exits without running deferred code natively (point 4 superseded by 0085: faults unwind).
- [0071-tcp-accept-read-write.md](0071-tcp-accept-read-write.md): prelude `Listener.accept` (net.listen) and `close`, `Conn.read(max) -> Bytes? ! NetErr` and `write` (net) and `close`; cancellation points reporting `Canceled`; close fails waiters with `Io`; Go backend via deadlines, native via the event loop.
- [0072-native-map-set.md](0072-native-map-set.md): native Map and Set are SSA structs of lists (keys, values, live flags, an open addressing slot table, count) with generated find/put/remove/rebuild and per type hash functions; value semantics and sharing come from List; `==` on maps and Float keys are not lowered.
- [0073-go-callback-deadlocks-and-replay.md](0073-go-callback-deadlocks-and-replay.md): a task blocked in a Go call that waits only for its stuck foreign callbacks is reported as XO-F001 with the Go call edge, once every goroutine's stack shows nothing else can move (real runs and test worlds); limits: nothing is reported while a Go runtime timer is pending (read through a linkname to runtime.timeSleepUntil, linked only into programs with Go callback adapters, falling back with a warning when the link fails; darwin and linux only), channel waits in Go are never reported. Under the deterministic scheduler foreign callback calls and lent Go call returns are admitted only at decisions after Go's goroutines settle, in a fixed order, so seeds reproduce them; recordings log them (`c<n>`, `go.callback`) and replays admit them at the same point; gobind format 4.
- [0074-native-http.md](0074-native-http.md): std for the native backends is written in Xo (`std/native/<name>.xo`, loaded by the checker for native builds, lowered in place of the std declarations) over C intrinsics; std/http (HTTP/1.1 server and client reproducing net/http, routing, middleware, request values), std/json (codecs per type, a parser with encoding/json's errors), std/log, Display and Debug, `main ! Error`, `==` on maps; differences (faults exit, no TLS) listed.
- [0075-arm64-code-placement.md](0075-arm64-code-placement.md): the native arm64 backend aligns neither functions nor loop tops (no 16, 32, or 64 byte setting was a win on every bench program on M4; loop tops at 64 cut placement spread but at a slower point); `XO_ARM64_LAYOUT` sets alignment and a `pad=K` function shift for placement sweeps; bounds check removal stays off (nbody 1.0 to 1.5 percent slower at every alignment). Bounds check part superseded by 0184.
- [0076-selfhost-lexer-differential.md](0076-selfhost-lexer-differential.md): self hosting starts with `selfhost/lexer`, a faithful Xo port of internal/lexer (text as `Bytes`, same codes and messages); `lexer.Dump` and the Xo dump print one canonical format, and `internal/selfhost` requires byte identical output on every repo `.xo` file, the spec blocks, all runes, and a seeded mutation corpus (also under `-short`); gaps are recorded, not fixed by changing the language for the port.
- [0077-native-scheduler-go-style.md](0077-native-scheduler-go-style.md): the native task scheduler follows Go's: 256 slot run queues with half stealing, runnext with a 50 us grace, root threads run work while they wait, Go's spinning rule, futex locks and parks, a lock per cancellation node, one atomic per scope, deadlock checked when workers go idle.
- [0078-bytes-builder.md](0078-bytes-builder.md): `BytesBuilder` (new, with_capacity, write, write_byte, write_str, write_rune, len, freeze) builds `Bytes` in amortized O(1); move only like `StrBuilder` (XO0510).
- [0079-runes-as-numbers-and-text-helpers.md](0079-runes-as-numbers-and-text-helpers.md): a rune literal where an integer type is expected is its code point (8 bit types take only ASCII); `Int(r)`, `Rune(n)` (faults off a scalar value), `Rune.try(n)`; Unicode and quoting helpers on Rune, Str, and Bytes.
- [0080-xo0305-default-arm-on-large-enums.md](0080-xo0305-default-arm-on-large-enums.md): XO0305 is not reported for a `_` arm hiding at least 8 variants and more than half of the enum (a default); its message lists at most 8 hidden variants then "and N more"; meaning unchanged.
- [0081-native-sized-ints-bytes.md](0081-native-sized-ints-bytes.md): native backends: sized integers and Rune in the Int word (checked arithmetic and conversions through C, UInt64 ordered by a sign flip, widening as `iconv`), `b[i]` inline, slicing, builders as their text, `fs.read`/`env.args`/`proc.exit`, constant collections built once per run; selfhost/lexer builds and matches on all three backends.
- [0082-native-mutex-move-and-wake-one.md](0082-native-mutex-move-and-wake-one.md): native Mutex wakes only who can enter (oldest writer, else all readers) into the run ring, `with` moves the value into a `var` closure that hands back the old value on failure or unwinding (in place updates), `Map.remove` clears only the live flag until a rebuild.
- [0083-no-gc-builds.md](0083-no-gc-builds.md): `--no-gc` on build, run, test, check picks a native backend (arm64 on arm64 hosts, else LLVM); XO1201 (new 12xx group) reports every construct, std API, or effect the native backends cannot build, at its site, planned or impossible (`use go`); the check is the SSA builder itself, held to the code generators on every golden by TestNoGCCheckAgrees; native std/crypto (C), std/sql (in memory driver ported to Xo), and test binaries (one process per test, a C test world with a virtual clock, seeded Rand, in memory listeners).
- [0084-go-asm-hybrid.md](0084-go-asm-hybrid.md): Deprecated (owner, 2026-10-22: a plain Go build with a warning, to be removed): `xo build --hybrid` compiled eligible loops of the main module (no allocation, scalars and Lists of flat structs) to Go assembler with the arm64 backend's Go mode, Go versions kept under tag `xo_pure`; an option, not the default (native speed for numeric kernels, but little qualifies; preemption added by 0131).
- [0085-native-contracts-and-fault-unwinding.md](0085-native-contracts-and-fault-unwinding.md): native backends check `ensures` (wrapper around the body, `old` and `result`, on success only) and struct invariants (literals, `with`, `var` methods) with the Go backend's messages and locations; hybrid builds no longer exclude them. Faults unwind natively through the platform unwinder (forced unwind, `xo_personality`, call frame information and call site tables on arm64, `invoke` on LLVM) into landing pads that are the SSA's cleanup paths (deferred code, scope closes, Mutex unlocks, releases), no cost on the no-fault path; tasks, `task.isolate`, and HTTP handlers (500) catch them as on the Go backend.
- [0086-modules-and-workspaces.md](0086-modules-and-workspaces.md): Go style modules (MVS, git fetch, `xo.lock`, vendoring, no install scripts) plus effect ceilings per dependency, checked semver at publish, and `xo.work` as the only local override (Accepted; steps 1 to 4 implemented 2026-10-09: `require`, MVS, git fetch, `xo.lock`, `xo get`, `xo mod tidy`, `xo vendor`, offline, `xo.work`, effect ceilings, `xo publish --check`, `xo init`, `/vN` paths). - [0087-habit-diagnostics.md](0087-habit-diagnostics.md): code written with Go, Rust, TypeScript, Python, Swift, or Kotlin forms gets one diagnostic per habit naming it and the Xo form, a machine fix only when one rewrite keeps the meaning, and recovery that prevents cascades; new code XO0177 for syntax habits, existing specific codes gain notes and fixes; did you mean fixes only when clear; the lexer stays unchanged (habits in a parser token pass).
- [0088-codex-std-gaps.md](0088-codex-std-gaps.md): `Clock.sleep_or_cancel` returns cancellation as `ClockErr.Canceled` (sleep still unwinds); stdin reads are cancellation points and a stop request ends them with `IoErr.Canceled`; tuples are JSON arrays; `Duration.parse -> Duration ! - [0102-native-fs-and-stdin.md](0102-native-fs-and-stdin.md): Implemented: natively an Fs is its root and mode; every Fs method and attenuation in Xo over small C system calls; standard input waits on the poller (cancellation and stop requests end it); a late with_timeout closure is TimedOut.

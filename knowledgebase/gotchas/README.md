# Gotchas

One file per gotcha: symptom, cause, fix or workaround. Mark each as
`Observed` (it actually happened) or `Anticipated` (known in advance, not yet hit).

- [fe-cache-replay-queued-jobs.md](fe-cache-replay-queued-jobs.md): Observed 2026-10-19, fixed: the front end cache replayed a contract-wrapped body without the inner body job it queued, so the second build of a program with `ensures` failed loudly; entries are only recorded for bodies that queue declares' Body jobs alone.

- [amd64-fault-operand-spilled-slot.md](amd64-fault-operand-spilled-slot.md): Observed 2026-10-19: an amd64 overflow fault printed the wrapped sum as an operand when the result was spilled to the operand's slot; x86_recover_operand recovers from slots too
- [rewrite-moves-source-columns.md](rewrite-moves-source-columns.md): Observed 2026-10-18: a rewrite with the same lowering (0260 step 3) moved source columns, which DWARF and fault strings carry, so no binary was byte identical; compare with scripts/asmnorm.py

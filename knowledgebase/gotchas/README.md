# Gotchas

One file per gotcha: symptom, cause, fix or workaround. Mark each as
`Observed` (it actually happened) or `Anticipated` (known in advance, not yet hit).

- [go-integer-overflow.md](go-integer-overflow.md): Go integers wrap silently; generated code calls checked rt operations.
- [go-map-iteration-order.md](go-map-iteration-order.md): Go map order is random; Xo `Map` is an insertion ordered entry log plus hash index in rt.
- [go-line-directives.md](go-line-directives.md): `//line` directive rules; lines after a directive count up, so the generator repeats it per Go line; relative paths kept verbatim; line but no column at run time.
- [defer-differs-from-go.md](defer-differs-from-go.md): Xo `defer` is block scoped; blocks with defer run as closures.
- [extension-availability-checks.md](extension-availability-checks.md): Linguist misses non source extensions.
- [value-semantics-lost-update.md](value-semantics-lost-update.md): forgetting to write back a mutated copy loses the update silently.
- [spec-examples-drift.md](spec-examples-drift.md): spec examples that break spec rules get copied by agents.
- [predeclared-names-collide.md](predeclared-names-collide.md): `err`, `result`, `test` are taken by the language.
- [sticky-cancellation-blocks-cleanup.md](sticky-cancellation-blocks-cleanup.md): cleanup in defer fails after cancellation (spec 0.2).
- [root-module-absorbs-bench-go.md](root-module-absorbs-bench-go.md): `go test ./...` at the root picks up Go code under bench/; use `./internal/... ./cmd/...`.
- [type-args-vs-index.md](type-args-vs-index.md): how the parser tells `f[T](x)` from `xs[i]`, and the `m[Red](x)` trap.
- [fn-type-return-takes-uses.md](fn-type-return-takes-uses.md): `-> fn(A) -> B uses e {` gives the effect to the returned type, not the declaration.
- [parser-error-cascades.md](parser-error-cascades.md): how the parser avoids double reports and cascades after an error.
- [gopls-nested-module-noise.md](gopls-nested-module-noise.md): editor "undefined" errors in bench Go code are workspace noise.
- [macos-temp-path-realpath.md](macos-temp-path-realpath.md): `/var` vs `/private/var` broke finding comparison.
- [checker-error-type-hides-bugs.md](checker-error-type-hides-bugs.md): a checker bug that yields `<error>` silently disables checking; how to find it.
- [checker-hint-binds-open-error.md](checker-hint-binds-open-error.md): unifying a generic call's result with the expected type before its error type is known.
- [checker-generic-effects-per-call.md](checker-generic-effects-per-call.md): inferred effects of generic methods must be instantiated at each call.
- [effect-elision-result-type.md](effect-elision-result-type.md): an omitted effect argument in a result type is inferred, not a caller's variable.
- [tuple-field-float-lexing.md](tuple-field-float-lexing.md): `t.0.1` would lex as `t.` and the float `0.1`; numbers after `.` are indexes.
- [group-task-from-field-cannot-fail.md](group-task-from-field-cannot-fail.md): tasks on a task group from a field or parameter must handle their errors (XO0801).
- [xo-mod-modules-absolute-paths.md](xo-mod-modules-absolute-paths.md): modules loaded through xo.mod keep absolute paths in test output.
- [xo0520-misses-read-after-mutation.md](xo0520-misses-read-after-mutation.md): deleting a write back is not caught if the stale copy is read later.
- [codegen-var-receiver-spill.md](codegen-var-receiver-spill.md): spilling a `var` receiver into a temporary loses its mutation.
- [go-instantiation-cycle.md](go-instantiation-cycle.md): a generic method returning its type with other arguments is a Go instantiation cycle.
- [go-enotempty-is-errexist.md](go-enotempty-is-errexist.md): `errors.Is(ENOTEMPTY, fs.ErrExist)` is true; test errnos first.
- [virtual-clock-wake-before-block.md](virtual-clock-wake-before-block.md): the test clock must count a woken task as running before it runs.
- [canceled-sleep-unwinds.md](canceled-sleep-unwinds.md): `clock.sleep` unwinds a canceled task, so polling `is_canceled` around it never sees cancellation.
- [spawn-background-never-result.md](spawn-background-never-result.md): `spawn_background` with an infinite loop closure fails inference (XO0402).
- [go-constant-float-division.md](go-constant-float-division.md): `0.0 / 0.0` is a Go compile time error; float division goes through rt.
- [recursive-struct-option.md](recursive-struct-option.md): a struct containing itself through Option needs `rt.Box`.
- [virtual-timer-callback-holds-world-lock.md](virtual-timer-callback-holds-world-lock.md): virtual timer callbacks hold the world lock; do real work on a goroutine counted as running (`stopState.after`).
- [map-copy-claims-log.md](map-copy-claims-log.md): Map copies share one entry log; the first write claims it, other copies fork; why transient trie nodes were unsound in Go.
- [scope-send-hangs-run.md](scope-send-hangs-run.md): a task blocked on a send that is received only after its scope hangs `xo run` silently.
- [mono-fault-go-frames.md](mono-fault-go-frames.md): under `--mono` fault stacks name specialized copies and lack inlined closure frames; messages and locations are unchanged.
- [generic-constraint-no-adapter.md](generic-constraint-no-adapter.md): a fallible constraint method on a type whose method cannot fail faulted with "does not implement the interface" (fixed: adapters in copies, an adapter registry for generic code).
- [xo-test-writes-regressions.md](xo-test-writes-regressions.md): `xo test` writes regressions_test.xo into the tested module; test protected solutions from a copy.
- [checked-arith-inline-budget.md](checked-arith-inline-budget.md): generic rt arithmetic and out of line fault calls kept checked code from inlining (fixed: panic valued faults, constant forms, range analysis).
- [panic-valued-fault-stack.md](panic-valued-fault-stack.md): a fault raised as a plain panic value must become a `*FaultErr` at the first recover, or its stack lists the wrong frames.
- [range-over-func-loop-cost.md](range-over-func-loop-cost.md): `for i in a..b` through `rt.Range.All()` cost a closure call per iteration and an extra fault frame; range literals are counted loops.
- [build-dir-shared-across-xo-versions.md](build-dir-shared-across-xo-versions.md): older xo binaries failed on build directories a newer xo wrote; the build hash carries a layout tag.
- [bench-host-timing-drift.md](bench-host-timing-drift.md): host clock drift moves benchmark times by up to 10 percent; interleave before and after runs.
- [sync-pool-drops-on-gc.md](sync-pool-drops-on-gc.md): a `sync.Pool` empties at every GC, so request arenas pooled in one were barely reused; use a bounded channel.
- [closed-loop-latency-confound.md](closed-loop-latency-confound.md): with a closed loop load generator a slower server shows lower latency; compare latency only at equal throughput.
- [arena-handler-not-confined.md](arena-handler-not-confined.md): with `--arenas`, a handler that passes `req` on, reads `req.headers`/`req.body`, or captures it gets a heap copy, not an arena.
- [go-bind-cache-in-source-tree.md](go-bind-cache-in-source-tree.md): `use go` bindings are cached in `<project>/.xo/gobind`; tests set `XO_GOBIND_DIR`, `.xo/` is gitignored.
- [go-bind-name-mapping.md](go-bind-name-mapping.md): Go names become snake_case, keywords get `_` (`regexp.match_`), prelude type names get the package prefix (`url.UrlError`); read the generated `.xo` file.
- [go-handles-shared.md](go-handles-shared.md): handles of Go objects are shared references; a setter on one copy is seen through all.
- [first-signal-no-longer-cancels.md](first-signal-no-longer-cancels.md): since 0.7 the first SIGTERM only requests a stop; cancellation follows after 30s or a second signal.
- [std-method-effect-only-go-method.md](std-method-effect-only-go-method.md): a std method whose only own type parameter is an effect (`Once.get[fx]`) is called as the Go method `M_get`, not `Task_Once_get`.
- [run-main-without-error.md](run-main-without-error.md): `testing.run_main(main, os)` with `fn main(os: Os)` (no `!`) fails the Go build; declare `main` with `!`.
- [permit-handoff-after-cancel.md](permit-handoff-after-cancel.md): a canceled item's permit release can wake the spawn loop, which then started one more item; recheck cancellation after acquire.
- [golden-tie-insertion-order.md](golden-tie-insertion-order.md): arena_escape's `longest` ties depended on concurrent insertion order (fixed: ties broken by value).
- [fmt-line-indent-set-on-first-write.md](fmt-line-indent-set-on-first-write.md): the formatter fixes a line's indentation at its first write; write the continuation token before restoring `p.indent`.
- [fmt-comments-in-joined-lists-move.md](fmt-comments-in-joined-lists-move.md): `xo fmt` moves a comment inside a one line list to after the statement; break after the opening bracket to keep it.
- [fmt-empty-block-is-map.md](fmt-empty-block-is-map.md): `{}` in an arm body or expression statement is an empty Map, not a block; write `()`.
- [go-flag-stops-at-first-argument.md](go-flag-stops-at-first-argument.md): Go's flag package stops at the first positional argument; `xo query` scans flags itself.
- [busy-loop-starves-deterministic-scheduler.md](busy-loop-starves-deterministic-scheduler.md): a loop without scheduling points keeps the turn forever under `--seed`; `task.is_canceled()` is a scheduling point.
- [go-select-random-choice.md](go-select-random-choice.md): Go's select is random among ready cases; runtime waits decide wake up versus cancellation from state.
- [stale-wakeup-after-early-leave.md](stale-wakeup-after-early-leave.md): a wake up landing after a task left its wait would skip its next block; waits end only after their wakers are claimed or done.
- [runtime-callers-per-block-cost.md](runtime-callers-per-block-cost.md): `runtime.Callers` on every block doubled channel handoff cost; real runs recover call sites from the goroutine profile instead.
- [scope-last-statement-line-directive.md](scope-last-statement-line-directive.md): the last statement of a scope body reported the next line (`pre` written after its `//line`); fixed in codegen.
- [macos-clt-sdk-link-failure.md](macos-clt-sdk-link-failure.md): clang fails to link with the Command Line Tools SDK 27 ("unknown architecture arm64e.x1"); `xo build --backend=llvm` tries other SDKs and remembers the one that links.
- [go-backend-list-set-quadratic.md](go-backend-list-set-quadratic.md): `xs[i] = x` copied the whole list on the Go backend, so element write loops were O(n^2) (fixed 2026-10-08: in place writes for the unique owner).
- [list-own-marks.md](list-own-marks.md): Lists write in place while unshared, so every copy site must mark (own reads by default, borrows checked); rules for changing codegen or rt.
- [go-generic-shape-inline-budget.md](go-generic-shape-inline-budget.md): generic List methods with a copy call exceed Go's inlining budget per shape; generated code uses small value receiver write forms.
- [go-large-struct-element-copy.md](go-large-struct-element-copy.md): `xs[i].f` copied the whole element when it has more than four fields; field reads use `RefM`, only when the statement cannot write the list.
- [gen-source-cache-race.md](gen-source-cache-race.md): parallel golden tests crashed on gen's unlocked source cache map (fixed with a mutex).
- [xo0520-in-generated-tests.md](xo0520-in-generated-tests.md): random value semantics programs fail the lost update check; store through a call (`m[k] = id(c)`).
- [macos-first-run-latency.md](macos-first-run-latency.md): the first run of a new binary waits about 0.2 s on macOS checks; time best of N.
- [go-negative-zero-literal.md](go-negative-zero-literal.md): `-0.0` is a Go constant without a sign, so the Go backend prints `0.0` where the LLVM backend prints `-0.0`.
- [llvm-format-verb-in-ssa-name.md](llvm-format-verb-in-ssa-name.md): SSA names like `%t3` concatenated into a format string are read as verbs; pass them as arguments.
- [llvm-list-write-cost.md](llvm-list-write-cost.md): out of line list write helpers made LLVM builds 2 to 5x slower than Go; inline fast paths, TBAA tags, and a per block uniqueness cache fixed it.
- [llvm-borrow-and-var-alias.md](llvm-borrow-and-var-alias.md): a list passed both as `var` and by value aliased in the LLVM backend; by value arguments of calls with `var` parameters are retained.
- [go-backend-tuple-arity.md](go-backend-tuple-arity.md): tuples longer than six elements pass `xo check` but fail the Go build (`rt.Tuple11` undefined).
- [record-replay-scheduler-decisions.md](record-replay-scheduler-decisions.md): a seed does not replay a real run; the recording logs every pick and every outside event (timers, signals, requests) at decisions.
- [ring-replay-other-requests.md](ring-replay-other-requests.md): an `XO_RING` crash bundle replays main's startup and the failing request only; state from other requests needs `--record`.
- [go-build-cache-growth.md](go-build-cache-growth.md): Xo builds filled Go's build cache; now a separate capped cache.
- [go-cache-trim-races-builds.md](go-cache-trim-races-builds.md): the capped cache trim deleted entries a concurrent build was linking; keep entries younger than 2 hours and restat before removing.
- [serve-tests-and-stale-server.md](serve-tests-and-stale-server.md): `xo check` and `xo query` forward to a running `xo serve`, which runs the code it was built from; tests set `XO_NO_SERVE=1`.
- [unix-socket-path-length.md](unix-socket-path-length.md): unix socket paths over 104 bytes fail on macOS; keep test sockets under a short temp dir.
- [mcp-stdout-is-the-protocol.md](mcp-stdout-is-the-protocol.md): `xo mcp` runs commands in process, so a direct write to os.Stdout corrupts the JSON-RPC stream.
- [xo-fix-applies-suggestion-fixes.md](xo-fix-applies-suggestion-fixes.md): `xo fix` also applies the nearest name guesses of XO0601; review the report or use `--dry-run`.
- [hash-brace-is-set-literal.md](hash-brace-is-set-literal.md): `#{"a": 1}` is a Set literal and derails the parser; maps are `{"a": 1}`.
- [sql-memory-driver-limits.md](sql-memory-driver-limits.md): the std/sql in memory driver is an SQL subset; an unfinished Tx holds a pool permit (always defer a rollback).
- [middleware-identity-header-spoofing.md](middleware-identity-header-spoofing.md): with no request locals, auth middleware passes the user in a header; always overwrite it or clients can spoof it.
- [numeric-conversion-is-call.md](numeric-conversion-is-call.md): convert with `Float(n)`, not `Float.from(n)`; XO0601 gives no hint.
- [lock-convoy-runnext-wake.md](lock-convoy-runnext-wake.md): a FIFO handoff lock convoys because Go runs a woken goroutine only when its waker blocks; barge and Gosched after waking.
- [lock-spin-starves-holder.md](lock-spin-starves-holder.md): spinning before parking on the runtime lock (Gosched or busy loop) cut HTTP throughput 3x to 6x.
- [ssa-braun-incomplete-phi.md](ssa-braun-incomplete-phi.md): sealing a block must use the recorded incomplete parameter, not `defs[var][block]`, which a later write replaces.
- [ssa-generic-func-value-targs.md](ssa-generic-func-value-targs.md): the checker records no type arguments for a generic function used as a value; the SSA builder matches its signature against the value's function type.
- [ssa-heap-visited-set.md](ssa-heap-visited-set.md): `Type.Heap`'s recursion guard was a visited set, so two `Int` fields made a struct "heap"; use a path set.
- [rc-verifier-loop-param-leak.md](rc-verifier-loop-param-leak.md): an RC verifier that sets block parameter counts on entry hides a leak of the previous iteration's value; check they are zero first.
- [rc-verifier-stop-block-merge.md](rc-verifier-stop-block-merge.md): predecessors of an `unreachable` or fault block need not agree on what they hold (nothing is released there); the RC verifier merges them.
- [snprintf-int-formatting-cost.md](snprintf-int-formatting-cost.md): `snprintf("%lld")` dominated Int interpolation in the LLVM runtime (4x slower workload); use a digit loop.
- [arm64-stp-pair-order.md](arm64-stp-pair-order.md): on Apple M4, `stp x19, x20` for callee saved registers made recursive fib 1.4x slower than `stp x20, x19`; store pairs high register first.
- [arm64-loop-carried-store-forwarding.md](arm64-loop-carried-store-forwarding.md): a list length stored and reloaded every push iteration bound the native sieve on store to load forwarding; keep loop carried values in registers.
- [arm64-zero-word-values.md](arm64-zero-word-values.md): `()` and capabilities have no words in the native backend; check the type before reading word 0.
- [arm64-cheap-constants-across-blocks.md](arm64-cheap-constants-across-blocks.md): sharing one instruction constants across blocks blocks coalescing and costs a register and a copy; make them again per block.
- [arm64-nested-helper-labels.md](arm64-nested-helper-labels.md): a helper generator that recurses must take its label number before the recursion advances the shared counter (duplicate `Lxo_drop6_v1`).
- [ssa-option-first-recursive-type.md](ssa-option-first-recursive-type.md): a recursive struct first met as `T?` is not boxed by the SSA builder, so both native backends reject it; use the struct before its Option until the builder is fixed.
- [gocache-trim-races-concurrent-build.md](gocache-trim-races-concurrent-build.md): one xo process trimming the shared Go cache can delete entries a concurrent `go build` reads ("could not import os"); rerun, or separate `XO_GOCACHE`.
- [arm64-match-dispatch-prediction.md](arm64-match-dispatch-prediction.md): on Apple M4 a jump table sped interp up 1.8x but lost up to 3x on random tags; chain layout (taken branch per failed test) was most of interp's cost.
- [native-float-nan-order.md](native-float-nan-order.md): the LLVM and arm64 backends compare Float with IEEE `<` (NaN false), the Go backend with the spec's total order (NaN last).

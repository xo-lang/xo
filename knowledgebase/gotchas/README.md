# Gotchas

One file per gotcha: symptom, cause, fix or workaround. Mark each as
`Observed` (it actually happened) or `Anticipated` (known in advance, not yet hit).

- [hex-literal-past-int-max.md](hex-literal-past-int-max.md): Observed 2026-10-29: a Go uint64 constant past 2^63 fails XO0421; write it negative.
- [ab-scripts-shared-output-dir.md](ab-scripts-shared-output-dir.md): Observed 2026-10-28: two A/B scripts sharing one scratch directory (caches, std variants, binaries) deleted each other's state mid-run; a private directory per run
- [store-format-magic.md](store-format-magic.md): Observed 2026-10-28: a std store an older xo wrote faulted in store_view (out of range) because a layout change kept the magic; change STORE_MAGIC with every layout change
- [atom-label-before-function.md](atom-label-before-function.md): Observed 2026-10-28: a runtime function's unsafe range start label precedes its own label, so per-function tables (std store builds) gave it to the function before and the allocator had no table (SIGSEGV in alloc.alloc, 2 of 40 runs); a start label right before a function's label is that function's
- [amd64-baseline-sse2.md](amd64-baseline-sse2.md): amd64's baseline is SSE2 (Go's GOAMD64=v1); an SSSE3 or later instruction needs a cpu.hw() check, with TestX86SIMDGated and a bit-off fallback run
- [poly1305-64bit-limbs-slower-on-apple-arm64.md](poly1305-64bit-limbs-slower-on-apple-arm64.md): Go's 64 bit limb Poly1305 was 0.656 of the time on x86 but 1.174 on Apple arm64 with 0.667 of the instructions; amd64 only, --ab each architecture
- [readrequest-not-the-server-layer.md](readrequest-not-the-server-layer.md): Observed 2026-10-26: `parse_head` is the server's parser, so a differential against `net/http.ReadRequest` reads three server-only checks (`Host` required and well formed, a header name with a space) as parser divergences; the oracle applies `ValidHeaderFieldName` and keeps Host valid, which took 300 seeded raw-head cases from 125 failures to zero, and on the response side `RespHead.clen` is readTransfer's realLength (not `ContentLength`) and `close` is shouldClose (not `resp.Close`)
- [bounds-proof-short-circuit.md](bounds-proof-short-circuit.md): Observed and worked around 2026-10-26: `while i < left && j < hi` carries the second comparison in a phi, and the arm64 list index bounds proof reads comparisons only at a branch terminator, so `j` kept a check its guard had already justified; a loop plus a `break` guard records both (std's merge sort now says it that way, 0.909 of the instructions on the in-place int sort)
- [struct-heap-field-count-code-size.md](struct-heap-field-count-code-size.md): Observed and fixed 2026-10-26: three extra Map fields in the proof struct, which sits in the arm64 generator, made every copy or drop of a generator retain and release three more heap fields inline and grew xo's own `__text` by 215,336 B across about 50 emitter functions that never call the proof; one fact map keyed per kind brings it to +8,696 B
- [dev-edges-missing-binding.md](dev-edges-missing-binding.md): Observed and fixed 2026-10-26: `xo dev edges` on a `use go` program without its binding wrote only the standard library's references and exited 0, so a per-directory sweep measured every `use go` golden as a program with no calls; it now exits 1 naming the reason, and a sweep binds first (`xo bind --dir=DIR ...`)
- [amd64-clang-flags-do-nothing.md](amd64-clang-flags-do-nothing.md): Observed 2026-10-28: a clang or LLVM assembler flag (`-mbranches-within-32B-boundaries`) changes nothing in `xo build --backend=amd64`, which assembles and links with Xo's own tools; check the hot function's bytes before timing a layout experiment
- [profiler-high-rate-distortion.md](profiler-high-rate-distortion.md): Observed 2026-10-28: XO_PROF_HZ=10000 slowed a 109 ms build 5 to 10x and charged a task fiber's lexing to the main thread's current function; profile short processes at 100 to 1,000 Hz, merge runs with pprof -proto, and cross-check with absolute stamps
- [sort-by-tuple-key-and-map-list-append.md](sort-by-tuple-key-and-map-list-append.md): Observed 2026-10-28: sort_by with a (Int, Str) key was 4% of a cold compile (five growing lists, every element moved twice, strings compared); a list read from a map and pushed to is copied whole each time; sort an Int key with the pdqsort and gather, remove the list from the map before appending
- [arm64-bounds-check-two-sites.md](arm64-bounds-check-two-sites.md): Observed 2026-10-26: the index check is emitted twice over, in `g.bounds_check` (lists) and in the `bytes.index` lowering, and the length `bounds_check` holds is a register while `G.bounds`, `len_root` and the `Proof` predicates take SSA value indexes, so a rule added to one site or given the register compiles and silently never fires; `xo dev dump ssa` shows the shape
- [fakeclock-same-instant-go-order.md](fakeclock-same-instant-go-order.md): Observed and fixed 2026-10-26: the Go world fired every timer of an instant at once, so the woken threads were ready together and the seeded scheduler could run the later timer's task first (std.md 8.2 wants scheduled order); fireNextLocked now fires one timer per call, and a test of the order must schedule the second timer from a later clock point, not from spawn order
- [op-verify-immediate-radix.md](op-verify-immediate-radix.md): Observed and fixed 2026-10-26: XO_OP_VERIFY stopped on `movi v31.16b, #0x19` because the arm64 emitter writes six immediate masks in hex and print_op writes every immediate in decimal; op_round_trip now compares immediates by value and still rejects every other operand difference
- [stripped-traceback-header-symbol.md](stripped-traceback-header-symbol.md): Observed and fixed 2026-10-25: with the function symbols gone (`-s`, or a strip after the link) `__mh_execute_header` is the nearest symbol for every pc, so a traceback printed it as every frame and never stopped at main; prof now skips it and says the build has no function symbols, and a `--release` link keeps the __text names
- [build-signature-carries-file-name.md](build-signature-carries-file-name.md): Observed 2026-10-25: a darwin build embeds an ad-hoc signature whose identifier is the output FILE NAME, so two builds of the same tree to different names differ in a byte or a few and a hash comparison across names proves nothing; the same name in different directories is byte identical, and a rebuild to the measured path reproduces the measured binary
- [inline-asm-cfi-needs-uwtable.md](inline-asm-cfi-needs-uwtable.md): Observed and fixed 2026-10-25: a naked function's inline asm `.cfi_escape` needs a CFI region clang emits for a split part's codegen but not for the whole-program IR (TestGoldenTasks, TestRaceSyncTable), and the two directive forms exclude each other; the `uwtable` attribute makes clang open the region in both, so the bare escape compiles everywhere

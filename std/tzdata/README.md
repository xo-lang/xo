# std/tzdata

The IANA time zone database std/time embeds (decision 0094's addendum).

- [zoneinfo.zip](zoneinfo.zip): every zone's TZif data, stored, built by `scripts/tzdata-update.sh`.
- [VERSION](VERSION): the IANA release it was built from, the SHA-256 of its tzcode and tzdata archives, and their source.

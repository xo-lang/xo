# std/tabwriter changes

## 2026-10-29: port: std/tabwriter, Go's text/tabwriter

- Kind: port
- Commit: this commit
- Found by: the std-vs-Go survey (item 12: CLI tables were padded by hand)
- Go reference: text/tabwriter/tabwriter.go (Writer, Init, Write, Flush: format, writeLines, writePadding, the Escape and HTML filters) and tabwriter_test.go (go1.26.3)
- Test: internal/stdtest/testdata/corpus/tabwriter, generated by scripts/stdcorpus/tabwriter.go from Go's own test table, each case written all at once, byte by byte and in Fibonacci slices, on the native backends (arm64 and LLVM) and the Go backend
- Timing: the row against Go's text/tabwriter follows in a later entry

`tabwriter.writer(min_width, tab_width, padding, pad_char, flags)` makes a move only `TabWriter`; `write(bytes)` collects text and `flush()` returns it with the columns aligned. The native backends run an Xo port of Go's code (the Go backend runs Go's own Writer over a buffer): the output Go writes to its io.Writer as lines complete is held until `flush`.

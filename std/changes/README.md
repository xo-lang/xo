# Std change logs

One file per std module (decision 0276): every fix, port, behavior
change, security fix, new function, and notable speedup a user of the
module could notice, newest first, in the entry format of decision 0276
(heading `## YYYY-MM-DD: kind: summary`, then Kind, Commit, Found by,
Go reference, and Test lines, then one or two sentences). The website
publishes these files as they are.

Files are added as modules change; a module without a file has no
entries yet.

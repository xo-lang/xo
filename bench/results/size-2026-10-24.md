# Code size, b90df01a6 to main: hello and the CRUD server, 2026-10-24

Programs: `bench/perf/twins/hello/xo` (print one line and exit) and
`bench/perf/http/xo` (the CRUD server, release). Each commit was checked out,
its own xo built with `go run ./scripts/xobuild`, and both programs built
with that xo and that commit's std:

    ./bin/xo build --release -o OUT BENCHDIR

with `XO_INLINE_STRICT=1` and a private `XO_BACKEND_CACHE_DIR` per commit,
deleted after its builds (an old xo's prune would evict the shared cache).
The Mac, darwin/arm64, one run per row.

Measured by `go run ./scripts/sizebreak -reach -top=8` at main 4ff192270:
`__text` is the text section, checked against the sum of the symbol gaps
("symbol gaps cover N of N bytes" in every row); the file size is `ls -l`
and includes data and symbols; the groups are top 8 by bytes; unreachable is
the `-reach` lower bound (direct branches plus materialized addresses, no
indirect calls), so a symbol counted there may still run.

ADR 0371's hollow commit had not landed on main when this was measured (the
highest decision is 0370), so main is 4ff192270, the sizebreak commit.

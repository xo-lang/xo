## Spec contradictions in 0.2

1. **`uses (a, b)` on declarations.** Examples in core 6.2 and std 7 use
   parentheses; the grammar only allows them in function types. Hit by 3 agents.
2. **Implicit interface conversion.** Core 2.5 says there are exactly two
   implicit conversions; std 1 adds conversion to an interface type. Hit by 2.
3. **Sticky cancellation blocks cleanup.** A `defer` that removes a temp file
   performs a fallible blocking call, which reports `Canceled` after
   cancellation, so cleanup cannot run. Design bug (04).
4. **XO0520 scope.** It does not say whether `var` closure parameters
   (`Mutex.with(fn(var m) ...)`) or reads inside `defer` count. It also fires on
   a test that calls `b.take(now)` only for its return value (05). Hit by 3.

## Friction (rule followed, but costly)

1. **Value semantics still costs in concurrency.** Collecting worker results
   again needed `Mutex[Map]` plus a reorder pass (02). Atomic take and compute
   needed `Mutex.with` around `Map.update` and a result enum (05).
2. **Effect plumbing in generic code.** `fx: Effects`, effectful function types,
   and a `Clock` parameter just to time the run (02).
3. **Strings.** Raw strings cannot contain `"` and plain strings interpolate
   braces, so a JSON fixture cannot be written as a literal (03). Second run in
   a row where `{}` interpolation caused trouble.
4. **No `?` on `Option`.** Nested `if let` for header parsing (03).
5. **Newline rule.** A method chain cannot continue on a line starting with `.`
   (05).
6. **`json.Patch` handling** needs a three arm match per field (01).

## Proposed changes for 0.3

1. Allow `uses (a, b)` on declarations too (parentheses optional there).
2. State conversion to an interface type as the third implicit conversion.
3. `defer` blocks run shielded from cancellation, with a deadline (default 5s,
   faults after).
4. XO0520 applies only to a `var` initialized by copying an element out of a
   collection or `Mutex` (the real hazard). Reads in `defer` count. `var`
   closure parameters are exempt.
5. A block ending in a statement has type `()`; `while` with no `break` has
   type `Never` and may end a block.
6. Inference for generic struct literals and enum variants; qualified variant
   patterns in the grammar; unit variant names resolve before bindings.
7. Prelude: every builtin scalar, `Str`, `Bytes` implement `Display`; `Float`
   is `Ord` with NaN sorting last; `Duration` may be negative.
8. `os.fs` is rooted at the filesystem root and accepts absolute paths;
   relative paths resolve against the working directory; `os.fs.cwd() -> Fs`.
9. SIGINT and SIGTERM cancel `main`'s root scope (graceful shutdown).
10. "Pure" means "no capability effects"; synchronized state is allowed.
11. `Next` and `Router.call` carry the router's effects through an effect
    variable (`Router[fx]`), or document why registration covers them.
12. Module local name: last path segment with `-` mapped to `_`; `as` required
    if still not an identifier.
13. Interface satisfaction ignores `pub` on methods; std struct fields are `pub`.
14. `expect` available in all `_test.xo` files; document FakeClock ordering,
    MemFs mtimes (virtual now), `fail_next` matching (any path argument, root
    relative).
15. `?` on `Option` inside functions returning `T?`.
16. Leading `.` continues the previous line.
17. Decide Appendix B question 6 (`${x}` interpolation) and add raw strings
    that can contain quotes (`r#"..."#`).

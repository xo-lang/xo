# The compiler edit loop: rebuilding xo after a one-line edit (2026-11-05)

Owner-approved item (2026-11-05, ahead of native arenas): how long
`go run ./scripts/xobuild` takes after a one-line compiler edit, where the
time goes, and what fixed it. Gotcha:
[xobuild-edit-rebuilds-cold.md](../../knowledgebase/gotchas/xobuild-edit-rebuilds-cold.md).

Method: a worktree at a commit, one `// edit N` comment line added to
`module_scans` in compiler/ssa/build.xo per step (each step a new edit, as
when iterating on a change), built by `XO_XOBUILD_TIMES=1 go run
./scripts/xobuild` (xotool's step times, the build's `--phase-times` and
`XO_CACHE_STATS=1`); a std/native edit adds one comment line at the top of
std/native/llrt/unwind.xo. Mac: darwin/arm64, 24 GB, heavy.sh bulk slots,
shared with other agents' jobs (wall times vary by a few seconds with load).
Host 1: linux/arm64 offload host. Scripts: ~/xo-lead/notes/xo-lang-4/scripts
(editloop-mac*.sh, editloop-remote.sh, stablebuilder-remote.sh).

## Before: every edit rebuilt cold

Mac, main ec51bf372 plus the step timing:

| edit | total | build | front end hits | functions reused | objects reused |
|------|------:|------:|---------------:|-----------------:|---------------:|
| ssa 1 | 49.2 s | 40.4 s | 0/12,122 | 180/11,168 | 0 to 76/125 |
| ssa 2 | 64.6 s | 55.1 s | 0/12,122 | 180/11,168 | 0 to 76/125 |
| std/native | 59.9 s | 51.7 s | 0/12,122 | 0/11,168 | 0 to 76/125 |

xobuild's own steps: precheck 2.6 to 3.1 s, seed smoke 0.7 to 1.6 s, built
checks 1.7 to 2.4 s, `go run` about 1 s. Host 1 was the same (cold edit
builds about 52 s; a base build 102 s, two full builds, its seed more than
50 commits behind HEAD).

Causes (the gotcha): the builder was the previous edit's xo (a new codegen
key, so nothing cached under it); xobuild's per-edit stamps were in every
body's front end key; a second hop past `HopMax` built every edit with a new
xo.

## The ceiling: one fixed builder (host 1)

The same xo X0 building four successive edits (A to D): A, X0's first build
of these sources, cold; B and C hit 12,116/12,350 bodies, 22/23 module
checks, every rc, inline, function, object and part entry. D: 5.15 s wall,
3.26 GB max RSS, against about 52 s cold.

Run 3's first edit after a new builder (e1, 47.0 s, 0/12,122) is that
builder's first build of these sources: cold once, as in the ceiling run.

Run 4 still dropped a first pass of about 3.5 s in every edit ("the module
check cache skipped 1 module(s) a body of which was built from source
(compiler/xo)"): the root module's bodies key on the per-edit stamps, so they
always miss, and a skipped module with a miss makes the driver check again.
Run 5 checks the root module in full when the build is stamped
(Checker.mod_noskip_root): no dropped pass, build 5.7 to 6.3 s.

Result: a warm one-line compiler edit goes from 49 to 65 s to 10.7 to 13.7 s
on the Mac (4 to 6x); the first edit after a new builder is cold once (run
5's e1: 49.9 s).

What is left (run 5, ssa 3): check 0.9 s, fe.build 0.8 s, the rest of ssa
0.1 s, insert_rc 0.6 s, inline 0.5 s, hollow 0.5 s, the rest of the build
about 2 s; xobuild's built checks about 2 s; `go run` and git about 3 s.
std/native 1 (run 4) rebuilt 4,700 functions: a line shift in llrt moves the
debug lines of every function its code is inlined into. std/native 2's
`inline.verify` took 10.1 s against 0.4 to 2.0 s in every other build
(machine load or a real outlier: open).

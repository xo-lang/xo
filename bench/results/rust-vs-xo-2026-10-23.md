## Notes

- Not a quiet machine: other agents' jobs ran during the measurements. Every row waited for the 1 minute load average to drop under 5 and reports the load it started at (the "load at start" in the header is the moment the script began, before the first wait); `--ab` alternates the two programs each round, so a load change hits both alike, but treat ratios within 10 percent as ties.
- Every program prints a checksum and the runner stops when Rust's and Xo's differ; the CRUD servers were checked against the Go server on 26 requests (status, headers, body) by bench/perf/http/parity.sh.
- Rust is written as Rust is: axum on tokio with serde_json, `sort_unstable`-style loops, tokio tasks for the concurrency rows. pingpong and the other async rows are given on both tokio runtimes: the multi thread runtime wakes another worker per hop, the current thread runtime is the idiom for a channel ping pong.
- Wall, instructions and RSS include the process start; compute rows are 50 to 350 ms programs, so the start is under 2 percent.

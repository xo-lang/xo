replaces today. xo1 is built by the Go compiler with `--backend=arm64`

macOS, about ten other agents' work on the machine, so the wall clock
figures are noisy; the counts are what matters. Script:
the scratchpad's measure.sh and measure2.sh, which run the commands
below in order through the shared heavy lock.

## What the suites do not cover

`xo1` is still one directory per build, the host only on the Go
backend, and has none of `--race`, `--holes`, `--no-mono`,
`--no-arenas`, `--release`, `--ci`, `--seed`/`--explore` on the Go
backend's tests, `--record`, the binary cache, split LLVM builds,
`--real` tests, regressions_test.xo, or the check's diagnostics in its
own output (decision 0178 lists them as stage 1).

- Binding on a miss (selfhost/check bindmiss.xo `check_dirs_bound`): the

  xo1's builds use it.
- Fetching on a miss (`check_dirs_fetching`): a module version missing
  from the module cache is fetched with selfhost/cli/modules' mod.Download
  (passed in as a function: selfhost/check cannot import the module
  commands) and the run checked again; a failed fetch is the fetcher's
  problem (XO1302 with mod's message). `check`, `vet`, `doc`, `fix`,
  `audit`, `publish`, and xo1's builds fetch; `query` and `edit` do not
  (selfhost/cli/semantic cannot import the module commands, which
  import it).
- `xo publish` (all flags, JSON and text) and `xo get`'s API changes,

# TLS performance: the Xo TLS against Mbed TLS (2026-10-15)

The lead's TLS performance item (decision 0202; the zero-C push's 5%
bar). bench/perf/tls: crypto/tls servers (serve/, one listener per
configuration, HTTP/1.1 only so every request is a new connection and a
full handshake, 16 KiB records) and std/http's client (main.xo) built
with the Xo TLS (tls13.xo, tls12.xo; the default) and with Mbed TLS
(`XO_LLRT_C=tlsio`). Measured on the development Mac (Apple M-series,
arm64), `bench/perf/tls/measure.sh bin/xo OUT arm64 llvm` with N=50
handshakes and a 16 MiB body, through heavy.sh; the client's
instructions retired (min of 5 runs, /usr/bin/time -l) less its start
alone (N=0: 28.0M arm64, 25.2M LLVM, the same for both TLS sides), per
handshake or per MiB (a bulk run less one handshake). Wall times have
the 10 ms resolution of /usr/bin/time, so the Mbed bulk rates are rough.
The server side (tlssrv.xo against Mbed) follows once it lands.

Every handshake's chain is a leaf signed by an ECDSA P-256 CA, so each
one verifies at least one P-256 signature (two with an ECDSA leaf). Mbed
TLS refuses Ed25519 certificates (handshake_failure).

## Where the time goes (sample, LLVM)

- Handshakes: `nistec.mul` (the generic Montgomery product, CIOS over
  limbs in memory), `nistec.add` and `nistec.sub` take about 90% of the
  X25519 handshake's samples; the X25519 exchange itself
  (`ed25519.fe_mul`, `fe_sq`) about 5%. With RSA-2048, `bigmod.add_at`
  is the top frame, then nistec (the CA's signature).
- ChaCha20-Poly1305: `chacha.qr` about 70% (the quarter round on a
  List[Int] passed as var: a bounds check and a uniqueness check on
  every word), Poly1305's `tag` about 17%.
- AES-GCM: `aesgcm.shift_rows`, `sbox`, `add_round_key` (bitsliced AES,
  four blocks a pass, about 25 instructions a word in shift_rows) and
  `Gcm.mul` (constant time carry-less multiply). The code is already
  tight; Mbed uses the CPU's AES and PMULL instructions (about 1 cycle a
  byte). Mbed's 14M instructions a MiB is the rest of the stack (reads,
  copies, HTTP), a floor for both sides.

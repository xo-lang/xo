# Decision 0447 stage 4: wasip2 sockets against Rust (2026-11-03)

Second linux/arm64 offload host, alone on it. Programs and load generator: decision 0447's Stage 4 results. 
How each side was built and run:

- Xo: `xo build --targets=wasip2/wasm` (the default build; no flags).
- Rust 1.99.1: `cargo build --release --target wasm32-wasip2`, LTO,
  stripped. The size rows use `opt-level = "s"`; the load rows use
  `opt-level = 3` (cargo's release default,
  CARGO_PROFILE_RELEASE_OPT_LEVEL=3), see the second run below.
- Every server: `wasmtime run -S inherit-network=y -S
  allow-ip-name-lookup=y` (wasmtime 50.0.1), the same flags for all.
- Server design: wasm32-wasip2 has no threads, so Rust std's echo is one
  nonblocking loop over every connection that sleeps 50 us when nothing
  was ready; Xo's and wstd's run a task per connection over wasi:io's
  pollables. wstd is the like-for-like Rust row for the design.

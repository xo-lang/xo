- Linux 7.0.14-linuxkit aarch64, host 1 (the linux/arm64 timing host, exclusive lease; label added by hand 2026-11-22, the header of this run left it empty), 12 CPUs, load average at start 0.00

- node v20.19.2, typescript 5.9.3 (dist/ compiled on another host; no npm here), @types/node and typescript pinned in package-lock.json

Run on the linux/arm64 timing host (host 1) in two leases of at most 30
minutes (compute and json, then concurrency; the load line of each table
is its start), with the published xo 0.55.0 release binary against the
tree of task #687 (hence "NOT THIS CHECKOUT": the Xo programs are built

one process. The host has node but no npm, so the TypeScript was
compiled on the Mac by the typescript pinned in package-lock.json and
copied over (bench/perf/node/run.sh). The HTTP rows were not rerun; the
2026-10-23 file still holds them.

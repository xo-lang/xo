# amd64: loop layout, recoverable ties, push/pop frames (2026-10-17, xo-fa)

Decision 0254's third condition (measure amd64 against LLVM, replace
where the translation costs): the first three of the x86-only items in
Xo Lang 2's comparison (bench/results/amd64-vs-llvm-2026-10-17.md),
mine by the split with Xo Lang 2.

- Layout (x86emit.xo): blocks that only forward a jump are not laid out;
  a jump to a loop header that only tests emits the test there (one
  taken branch per iteration); a back jump to a header that starts with
  a check emits the check and a branch past it (lsr.xo rotate_jump's x86
  form).
- Ties of a checked add, sub, or neg (x86.xo x86_untie_recovered): the
  fault stub recomputes the operand from the result (recover), so the
  tied operand need not live past the copy into the result and the copy
  coalesces away (collatz's step was a copy, the add, and a copy back).
- Frames: the callee saved registers pushed and popped, not stored at
  offsets after a subq.

Two bugs found on the way: the ties' parallel moves did not list their
sources as uses (liveness reads uses; on main it was masked by the
instruction after the move reading the source too), and the untie must
keep a source that is also the definition (`p = p + k`).

## Block merging and wider load fusion (2026-10-17)

x86_merge_blocks folds each fall-through block with one predecessor into
it (with landing pad edges only when no value lives longer, gotcha
amd64-merge-pad-liveness), and x86_fuse_load takes a load from anywhere
earlier in the block when nothing between touches memory or redefines
its address registers. cachegrind instructions, linux/amd64 Docker:

| program | before | after |
|---|---|---|
| nbody | 5170034938 | 5020034133 (0.971) |
| strings | 1348878772 | 1347079536 (0.999) |
| collatz, fib, sieve, interp, sort | | unchanged (within 1000) |

Labels in nbody's assembly: 26621 to 20920. The 0.971 is the fused
loads of the hot loop (`subsd 24(%r9), %xmm12`); the next cost there is
the copy before each two operand operation whose first source was just
loaded (a load straight into the tie's destination).

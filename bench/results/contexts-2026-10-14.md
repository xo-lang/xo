# Contexts, budgets, and shields in Xo (B17), 2026-10-14

Work item B17 of `bench/results/zero-c-audit-refresh-2026-10-13.md`
(decision 0212 stage 3; decision 0229). Branch b17-contexts, three
stages:
- A: the shields of deferred code (ctx.xo).
- B: budgets (budget.xo: tick, open, end, charge, mark, pause, resume).
- C: the unwinding flag.
Generated code calls the Xo exports directly on arm64 and LLVM.
xo_rt.c: 287 lines deleted, 87 added.

## bench/perf/ctx (new), Mac, instructions retired

`bench/perf/ctx/measure.sh`, minimum of 5 runs.
- defer: 2,000,000 calls of a function with a defer, in a program that
  runs tasks, so the defers are shielded.
- mutex: 2,000,000 uncontended Mutex.with.
- spawn: 20,000 tasks in scopes of 10.
- budget: a 20,000,000 iteration loop under task.with_budget, polled at
  every iteration.
- The program calls with_budget, so every workload polls.

Main is 170c7e42, built by its own xo; the branch at stage C, built by
its own xo.

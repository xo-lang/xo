# Retain thunk, 2026-10-31

Measured: xo built at lang1-incthunk (on the shared landing pad tails,
main bd0bd05a5), darwin/arm64 on the Mac; then that xo builds
compiler/xo with the pass on and off (`XO_PASSES=-rc_thunk`). Last
verified: 2026-10-31.

## Why

`xo dev size --by-cause` with the rc cause split by operation (a
measurement build, not landed), xo's 51.19 MB of code before the tail
merge: inline retains of List, Box and Handle 10,264,492 bytes (20.0%),
of Str 1,366,544 (2.6%), struct dup calls 358,564 (0.7%), release and
drop calls 2,414,940 (4.7%). An inline retain is about 32 bytes: the
count's fast path (ldr, tbnz, add, str) and its own cold block for a
shared count (tbz, the atomic, b).

## In large loops too (2026-11-01)

is over 256 SSA values. Size: xo at 207777f69, darwin/arm64 on the Mac,
builds compiler/xo with the pass on and off (`XO_PASSES=-rc_thunk_loops`):
__text 35,639,004 to 33,811,420 (-5.1%).

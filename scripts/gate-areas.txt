# gate-areas.txt: the slow tests a per-push gate runs only when the change
# touches their area (lead, 2026-11-14, owner's test-time plan;
# scripts/gate.sh gate_skip, knowledgebase/infrastructure/toolchain.md
# "Gate test areas"). The 8-hourly full tier (XO_GATE_LLVM=all, as tier.sh
# and offload-tier.sh set it, or XO_GATE_TESTS=all) runs every test.
#
# Lines:
#   @NAME REGEX            an area: an extended regex over the changed paths
#   PKG TEST AREA...       TEST (a top-level test of PKG) runs in a gate when
#                          a changed path matches one of the AREAs (@NAME or
#                          a regex); "tier" alone: never in a gate (another
#                          gate step or the tier runs it, said in a comment)
#   PKG * AREA...          every listed test of PKG runs when one matches
#
# A test not listed here always runs. A test whose own _test.go file the
# change edits always runs. Background: in 2 days of gates the llvm step took
# 35 to 68 minutes even when it selected 0 or 1 golden programs (the TLS,
# crypto and runtime tests ran every time), and the arm64 step 18 minutes
# on average (bench/results/gate-time-2026-11-14.md).
